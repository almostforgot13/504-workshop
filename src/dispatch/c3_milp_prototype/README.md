# B / C3：15 分钟样例日 MILP

这是供团队审阅的 C3 小样本优化器。使用现有候选参数，不调整设备容量。输入为 A 的虚拟园区 15 分钟数据，示例取 2017-01-05 UTC，共 96 步。数据属于训练期，不能作为封存测试成绩。

## 运行

需要 Python 3.10+、NumPy 和 SciPy（使用 `scipy.optimize.milp` / HiGHS）。从此目录运行：

```powershell
python milp_model.py --input <A_15min_virtual_2017_2019.csv 的路径> --day 2017-01-05 --output sample_day_2017-01-05.csv
```

同时写出 `sample_day_2017-01-05.json`。未求得最优解时不写调度 CSV，JSON 保留求解状态，程序退出码为 2。

## 约束与核验

- 15 分钟功率平衡；购电上限；失负荷不超过客户负荷；弃电/总线多余功率显式记录。
- 电池充放电互斥；制氢槽与燃料电池互斥；两者最小开机功率和最大功率。
- 电池能量及氢库存递推与上下限；电池有符号净功率、制氢槽、燃料电池逐步爬坡。
- 求解后逐步调用 `device_model.apply_dispatch` 独立于矩阵约束的设备状态检查，报告最大功率平衡残差。

目标权重为演示假设：购电 1、弃电 0.1、失负荷 100（均按每 kWh 计的无量纲权重）。**这些不是团队确认的电价或成本参数。** 当前未规定日末库存价值/约束，优化器可能耗尽可调库存；因此不能将本日目标值用于四策略优劣比较。下一阶段滚动优化需要统一成本、终端库存处理和安全回退规则。

## 本次样例结果

2017-01-05：HiGHS 报告最优，MIP gap 0；96 步物理检查通过，最大平衡残差约 `4.8e-12 kW`。演示目标值 `8859.55`，对应购电 `8859.55 kWh`、弃电 `0`、失负荷 `0`。日末电池 `300 kWh`、储氢 `60 kg`，恰为允许下限，说明上述终端库存限制是后续比较前必须解决的事项。
