# AIC 技术报告写作材料

- 主文件：`AIC_AI能源技术报告_科技创新组_可填写模板.tex`。页眉图片 `AIC_页眉标志.png` 在同一目录，可继续编辑并编译。
- 竞赛要求与技术报告参考大纲：`竞赛参考文件/`。
- B 补充实验中可用于写作的报告、7 张图及 5 张关键数据表：本目录的 `实验结果报告.md`、`图像/`、`数据表/`。LaTeX 可用 `\includegraphics{图像/文件名.png}` 引用。
- B 2026-10-14 完整实验包：仓库 `src/dispatch/b_validation_2026-10-14/`，含源码、冻结模型、全部结果及复现说明。
- A 的预测源码及说明：仓库 `src/forecast/a_15min/`；虚拟数据：`data/processed/A_15min_virtual_2017_2019.csv`；B 的 2026-10-05 原交付：`src/dispatch/b_delivery_2026-10-05/`。
